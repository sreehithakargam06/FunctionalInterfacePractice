# Functional Interface Practice (Java 8)

This repository contains hands-on Java 8 practice programs focused on Functional Interfaces and Anonymous Inner Classes.

## Topics Covered

### 1. Custom Functional Interfaces
- Created `NumberChecker` functional interface.
- Created `CharChecker` functional interface.
- Implemented both using Anonymous Inner Classes.
- Checked whether a number is prime.
- Checked whether the ASCII value of a character is prime.

### 2. Predefined Functional Interface
- Used `Function<SensorData, Double>` to extract temperature.
- Used `Function<Double, Boolean>` to check whether the temperature exceeds the threshold.
- Implemented using Anonymous Inner Classes.

## Concepts Learned

- Functional Interfaces
- Anonymous Inner Classes
- Java 8 Features
- Function<T, R>
- Object-Oriented Programming
- Constructors
- Getters and Setters
